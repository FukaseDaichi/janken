# じゃんけん弾除けゲーム 設計書

日付: 2026-08-09
ステータス: 承認済み

## 概要

グー・チョキ・パーの形態を持つプレイヤーが、飛来する「たま」と「じゃんけんの手」を避け（時に倒し）ながら生存時間スコアを稼ぐ、PC ブラウザ向け全方位弾除けゲーム。GitHub Pages で公開する。

## 技術スタック

- TypeScript + Vite
- Canvas 2D 描画（ゲームエンジン不使用）
- GitHub Actions でビルドし GitHub Pages へ自動デプロイ
- ユニットテスト: Vitest（ピュアロジックのみ）
- 画像素材: Codex の `image-gen` スキルで生成したドット絵・イラスト素材

## 画面仕様

- PC ブラウザ向け、キーボード操作必須
- 内部解像度 960×720 固定。ウィンドウサイズに合わせてアスペクト比維持でスケール
- 画面フロー: タイトル → プレイ → GAMEOVER → （リトライで）プレイ

### タイトル画面
- ゲームタイトル、操作説明、じゃんけんルールの説明、ハイスコア表示
- キー入力（Enter / Space）でゲーム開始

### GAMEOVER 画面
- 最終スコア、到達レベル、ハイスコア（更新時は強調表示）
- リトライ（Enter / Space）でプレイへ

## ゲームルール

### プレイヤー
- 矢印キー（および WASD）で全方位アリーナ内を自由移動
- 形態はグー・チョキ・パーの3種。ゲーム開始時はランダム
- 現在形態と「勝てる手」を UI で常時補助表示

### 敵
1. **たま（弾）**: 画面外周から飛来。接触すると即 GAMEOVER
2. **じゃんけんの手**: 画面外周から飛来。接触時の判定:
   - 自分が**勝てる手** → 倒す（勝利カウント +1、ボーナススコア）
   - **あいこ**（同じ手） → GAMEOVER
   - **負ける手** → GAMEOVER

### レベルアップ
- レベル内でじゃんけんに **3勝**すると LVUP（勝利カウントはレベルごとにリセット）
- LVUP 時、プレイヤーの形態が**現在と異なる2種からランダム**で変化
- LVUP 時にフラッシュ演出＋形態変化アニメ

### スコア
- 時間経過で加算: 基礎レート × レベル倍率
- レベル倍率: LV1 = ×1.0、以降レベルごとに +0.5（LV2 = ×1.5、LV3 = ×2.0 …）
- じゃんけん撃破時にボーナス点を加算
- ハイスコアは localStorage に保存

## 難易度カーブ

時間経過とレベルの両方で以下が変化:

1. **スポーン間隔の短縮**（弾・手の数が増える）
2. **飛来速度の上昇**
3. **弾種の追加**（レベル進行で解放）:
   - 直進弾（初期）
   - 狙い弾（プレイヤー方向へ発射）
   - カーブ弾・加速弾（高レベル）

## アーキテクチャ

シンプルなクラスベース構成＋シーン分割の状態マシン。

```
src/
  main.ts            // エントリ: Canvas セットアップ、ループ起動
  game.ts            // Game: シーン管理、requestAnimationFrame ループ
  scenes/
    title.ts         // タイトルシーン
    play.ts          // プレイシーン（本体）
    gameover.ts      // GAMEOVER シーン
  entities/
    player.ts        // Player: 移動、形態
    bullet.ts        // Bullet: 弾種ごとの挙動
    hand.ts          // JankenHand: 手の種類と移動
    particle.ts      // 撃破・演出パーティクル
  logic/
    janken.ts        // 勝敗判定（ピュア関数）
    score.ts         // スコア計算・レベル倍率（ピュア関数）
    difficulty.ts    // 時間・レベル → スポーン間隔/速度/弾種（ピュア関数）
    level.ts         // 勝利カウント・レベル進行（ピュア関数）
  input.ts           // キーボード入力状態
  audio.ts           // Web Audio API による SE・BGM 合成
  storage.ts         // localStorage ハイスコア
  assets.ts          // 画像ロード
```

- 衝突判定は円同士の距離判定
- ピュアロジック（janken / score / difficulty / level / storage）は Vitest でユニットテスト
- 描画・入力・音は手動確認

## 演出・音

- 撃破時パーティクル
- LVUP 時フラッシュ＋形態変化アニメ
- GAMEOVER 時の画面シェイク
- Web Audio API で SE（撃破・LVUP・GAMEOVER）と簡易 BGM を合成（音声素材ファイル不要）

## 画像素材（Codex image-gen で生成）

ドット絵スタイル、背景透過 PNG:

- プレイヤー形態 ×3（グー・チョキ・パー、味方らしい可愛い見た目）
- 敵じゃんけんの手 ×3（グー・チョキ・パー、敵らしい見た目。プレイヤーと明確に区別できること）
- たま（弾）×1〜2種
- 背景画像 ×1（アリーナ）

視認性最優先: グー・チョキ・パーが一瞬で判別できること。
