# じゃんけんサバイバー — 手の出現頻度アップ + 弾の色分け

日付: 2026-08-09
ステータス: 承認済み

## 目的

1. じゃんけんの手の出現頻度を少しだけ上げる。
2. 通常弾を色分けし、色と弾種を1対1で対応させる。

## 非目標(やらないこと)

- 新しい弾種の追加(既存の `straight` / `aimed` / `curve` の3種を色分けするのみ)
- 弾の挙動・速度・サイズ・スポーン間隔(`bulletInterval`)の変更
- サイドパネルへの弾種凡例の追加(弾種は Lv3 / Lv5 で段階解放されるため、プレイ中に自然に学習できる)

## 1. 手の出現頻度アップ

`src/logic/difficulty.ts` の `handInterval` のみ変更する。

```
handInterval: Math.max(0.5,  3.0 - 2.5 * p)   // 変更前
handInterval: Math.max(0.45, 2.6 - 2.2 * p)   // 変更後
```

| 進行度 | 変更前 | 変更後 | 出現頻度 |
|---|---|---|---|
| p=0 (開始直後) | 3.00秒 | 2.60秒 | +15% |
| p=0.5 (中盤) | 1.75秒 | 1.50秒 | +17% |
| p=1.0 (最大) | 0.50秒 | 0.45秒 | +11% |

序盤から終盤までほぼ均等に約15%増やす。弾側は変更しないため、
「避ける対象」は据え置きで「倒せる対象」だけが増える。結果として
レベルアップ速度もわずかに上がる。

## 2. 弾の色分け

### 配色

弾は接触即 GAME OVER、手は勝てる手なら倒せる。**見間違いが致命的**なため、
弾の色は手のキーカラー(グー=緑 / チョキ=赤ピンク / パー=青)から
離れた色相を選ぶ。

| 弾種 | 色 | core | trail | edge |
|---|---|---|---|---|
| `straight` | 紫(現状維持) | `#e0b3ff` | `#be78ff` | `#a03cff` |
| `aimed` | オレンジ | `#ffd9a8` | `#ff9a3c` | `#ff6a00` |
| `curve` | シアン | `#bff4fa` | `#37e0e8` | `#00a8c8` |

### 配置

定数は `src/render/theme.ts` に一本化する(このリポジトリの既存方針)。
`HAND_COLORS` と同じ `Record<BulletType, ...>` パターンを使い、
全弾種の網羅を型で保証する。

```ts
export const BULLET_COLORS: Record<BulletType, { core: string; trail: string; edge: string }>
```

3値持つ理由: `src/entities/bullet.ts` の `draw()` はグラデーションを2つ使い、
計3箇所で色を指定している。

- テールの線形グラデーション: `trail` を α=0.55 → α=0 で使用
- 本体の放射グラデーション: 中心 `#ffffff` → `core` → 外周 `edge` の α=0

外周色は α=0 だが、Canvas のグラデーションは非乗算済み RGBA で補間するため
**色相が中間色の見た目に影響する**。1色や2色に畳むと現行の紫弾の見た目が
変わってしまうので、3値構成にする。

### 実装

`src/entities/bullet.ts` の `draw()` にハードコードされている紫リテラルを
`BULLET_COLORS[this.type]` 参照に置き換える。8桁 hex (`#RRGGBBAA`) による
アルファ指定は `src/entities/hand.ts` の既存パターンに合わせる。
**描画構造そのものは変更しない。**

  - 既存の下限アサーション `0.5` → `0.45` に更新

    (`CanvasRenderingContext2D` のスタブで `addColorStop` の引数を記録して検証。
    配色の配線ミス・コピペミスを検出する)
